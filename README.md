# Haoyang Jiang — Portfolio

Personal portfolio and résumé website, served at https://haoyangjang.github.io/.

This is a static HTML/CSS/JavaScript site. No build or installation is required.

- `index.html`: page structure and navigation.
- `content.js`: profile, experience, skills and projects.
- `publications.js`: publication cards and details.
- `styles.css` and `app.js`: presentation and interactions.
- `assets/`: portrait, project covers, previews and downloadable résumé.

Preview locally with `python -m http.server 8770 --bind 127.0.0.1`.

GitHub Pages publishes the repository root from the `main` branch. `.nojekyll` preserves static files without Jekyll processing.
